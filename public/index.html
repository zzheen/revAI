Новый клиент

Парсер Яндекс и Google Карт

Собирает публичные отзывы со страниц организаций по ссылкам из карточек клиентов. Работает через Chrome на этом компьютере, его окно открывается за пределами экрана. Повторный запуск добавляет только новые отзывы. Google без входа в аккаунт показывает лишь несколько отзывов: один раз выполните в терминале npm run google-login и войдите в Google в открывшемся окне.


        

        

          
Google: официальный API

          
Отзывы загружаются через официальный Google Business Profile API по карточкам, где ваш аккаунт владелец или менеджер. Ключи задаются в файле .env, а в карточке клиента указывается Google location.

          

          
          

        

        

          
Импорт CSV (Яндекс или Google)

          
Запасной вариант, если парсер не справился: выгрузка отзывов файлом. Колонки: дата;автор;оценка;текст, дата в формате ДД.ММ.ГГГГ ЧЧ:ММ.

          
          
          
          
          

        

        

          
Telegram: дневная статистика

          
Бот присылает администратору статистику по отзывам за день. Токен бота и id администратора задаются в .env, инструкция в README.
