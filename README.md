# RevAI v1: отзывы Google и Яндекс, черновики ответов, календари отзывов и встреч

Прототип по ТЗ «RevAI». Node.js + Express, интерфейс на чистом HTML/CSS/JS, данные в SQLite (встроен в Node.js).

## Запуск

Нужен Node.js 22.13 или новее.

```bash
npm install
cp .env.example .env      # заполнить ключи, см. ниже (можно пропустить)
npm start                 # http://localhost:3000
npm run google-login      # один раз: войти в Google для парсера (см. ниже)
```

База стартует пустой. Добавьте клиента во вкладке «Клиенты» со ссылками на Яндекс и Google Карты и нажмите «Источники» → «Загрузить отзывы с карт». Без ключей всё работает в упрощённом режиме: тональность по звёздам, шаблонные ответы.

## Что есть

- **Календарь отзывов** (вкладка по умолчанию): отзывы по дню появления. В каждом дне полоса тональности (зелёный/жёлтый/красный), число отзывов, разбивка Яндекс/Google, средняя оценка, `!N` для просроченных по SLA. Клик по дню открывает отзывы этого дня. Сверху показатели месяца.
- **Календарь встреч**: отдельный календарь встреч руководителя с клиентами. Клик по дню показывает встречи, там же добавляется новая — формой или фразой своими словами («завтра в 15:00 встреча с Матрёшкой»). Встречи также приходят из Telegram-бота (голосовые, текст, переписки), см. ниже. Сверху: встреч за месяц, на ближайшую неделю, занятые часы, следующая встреча.
- **Проблемы**: плохие отзывы (3★ и ниже или негатив) по видам проблем: официанты и сервис, кухня, цены и счёт, ожидание, гигиена, меню, комфорт. Для каждой проблемы: сколько жалоб, доля, динамика по месяцам, свежие цитаты. Клик по карточке показывает все отзывы с этой проблемой и есть ли на них ответ. Период: 3, 6, 12 месяцев или всё время.
- **Отзывы**: очередь с фильтром «Новый / Черновик готов / Одобрен / Есть ответ на площадке / Просрочен» и по площадке. Черновик можно одобрить, поправить, перегенерировать с пожеланием, скопировать. Публикация ответа на площадке делается вручную (п. 4.8 ТЗ).
- **Статистика**: тональность, оценки, Google против Яндекса, темы, сводка за месяц (текст пишет Claude, без ключа собирается из цифр).
- **Клиенты**: бриф (услуги, тон, контакты, стоп-слова), ссылки на Яндекс и Google Карты, Google location для официального API.
- **Источники**: парсер Яндекс и Google Карт, загрузка из Google API, импорт CSV.

## Источники отзывов

### Парсер Яндекс и Google Карт

Собирает публичные отзывы со страниц организаций по ссылкам из карточки клиента (например `https://yandex.ru/maps/org/rodina/1706232851/` и `https://www.google.com/maps/place/…`). Запуск: «Источники» → «Загрузить отзывы с карт», и автоматически каждые `PARSER_INTERVAL_HOURS` часов (по умолчанию 6). Первый прогон берёт до `PARSER_MAX_REVIEWS` последних отзывов (200) с каждой площадки, следующие добавляют только новые.

- Работает через Chrome или Edge, установленный на компьютере (пакет `playwright-core`). Окно браузера открывается за пределами экрана: в фоновом режиме обе площадки отдают пустую страницу. `PARSER_SHOW_BROWSER=1` в `.env` показывает окно.
- **Google без входа в аккаунт показывает только ~5 отзывов.** Один раз выполните `npm run google-login`, войдите в Google в открывшемся окне и закройте его. Вход сохранится в `data/browser-profile`. Лучше использовать отдельный аккаунт, не основной.
- Google отдаёт только примерную дату («3 месяца назад»), такие отзывы помечены «дата примерная». У Яндекса дата точная.
- Если на площадке уже есть ответ организации, он загружается вместе с отзывом. Такой отзыв получает статус «Есть ответ на площадке», не считается просроченным, и ИИ не пишет для него черновик (можно нажать «Перегенерировать»).
- Если площадка покажет проверку «я не робот», парсер остановится с ошибкой. Включите `PARSER_SHOW_BROWSER=1`, пройдите проверку в окне и повторите.
- Парсинг страниц не одобрен правилами Яндекса и Google, а вёрстка площадок меняется. Если парсер перестал находить отзывы, нужно обновить селекторы в `src/sources/maps.js`. Не ставьте интервал слишком частым.

### Google Карты: официальный API

Google Business Profile API отдаёт все отзывы и только по карточкам, где ваш Google-аккаунт владелец или менеджер.

1. В Google Cloud создать проект и подать заявку на доступ к Business Profile API (Google одобряет вручную).
2. Включить API «My Business Account Management» и «Google My Business API».
3. Создать OAuth-клиент, получить refresh token с областью `https://www.googleapis.com/auth/business.manage` (например через OAuth Playground).
4. Заполнить в `.env`: `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REFRESH_TOKEN`.
5. В карточке клиента указать Google location вида `accounts/123/locations/456`.
6. «Источники» → «Загрузить отзывы из Google».

### Импорт CSV (запасной вариант)

Если парсер не справился, отзывы можно загрузить CSV-файлом (выгрузка вручную или из сервиса-агрегатора отзывов):

```
дата;автор;оценка;текст
01.10.2026 14:20;Виктория;5;"Прекрасная клиника"
```

Разделитель `;` или `,`, дата `ДД.ММ.ГГГГ ЧЧ:ММ`, текст до 3000 символов. Повторная загрузка того же файла дублей не создаёт.

## Telegram-бот: встречи в календарь

Бот руководителя заносит встречи в «Календарь встреч». В календарь встреча попадает только после кнопки «✅ Добавить» — бот не создаёт ничего сам. Если время уже занято, бот предупредит.

1. **Голосовое или текст боту в личку**: «завтра в 15:00 встреча с Матрёшкой по отзывам на час», «в пятницу в 11 созвон с управляющим». Можно переслать боту сообщение с договорённостью из любого чата.
2. **Рабочие чаты**: добавьте бота в группу с клиентом или командой. В @BotFather выполните `/setprivacy` → выберите бота → `Disable`, иначе бот не видит обычные сообщения группы. Когда в чате договорились о времени («давайте созвонимся в понедельник в 11:00»), бот пришлёт руководителю в личку предложение добавить встречу.
3. **Личные переписки руководителя (Telegram Business)**: в @BotFather включите боту Business Mode (`/mybots` → бот → Bot Settings → Business Mode). Руководитель подключает бота в Telegram → Настройки → Telegram для бизнеса → Чат-боты и выбирает, к каким чатам дать доступ. Нужна подписка Telegram Premium. Дальше бот так же замечает договорённости в переписке и предлагает их добавить.

Команды: `/today` встречи сегодня, `/week` на 7 дней.

Разбор фраз: с `ANTHROPIC_API_KEY` встречу из текста и переписки понимает Claude (учитывает контекст последних сообщений чата, чистит тему). Без ключа работает простой разбор дат и времени («завтра», «в пятницу», «20 октября», «23.10», «в 15:00», «в 3 часа дня», «на полчаса»).

**Голосовые** распознаёт Yandex SpeechKit (работает в России, принимает голосовые Telegram без конвертации, до 30 секунд):
1. В Yandex Cloud (console.yandex.cloud) создайте платёжный аккаунт и каталог.
2. Создайте сервисный аккаунт с ролью `ai.speechkit-stt.user` и API-ключ для него.
3. Впишите ключ в `.env`: `YANDEX_SPEECHKIT_API_KEY=...` и перезапустите сервер.

## Telegram-бот: дневная статистика

Каждый день в `TELEGRAM_DAILY_TIME` (по умолчанию 20:00, по времени сервера) бот присылает администратору статистику за день: сколько отзывов пришло (и сравнение со вчера), средняя оценка по Google и Яндексу, позитив, нейтрально и негатив, частые темы, разбивка по клиентам, сколько ответов одобрено, сколько ждут проверки и сколько просрочено по SLA, плюс тексты негативных отзывов.

Настройка:
1. В Telegram откройте @BotFather, отправьте `/newbot`, задайте имя и username бота. BotFather пришлёт токен.
2. Впишите токен в `.env`: `TELEGRAM_BOT_TOKEN=...` и запустите сервер (`npm start`).
3. Напишите своему боту `/id`, он ответит вашим Telegram id.
4. Впишите id в `.env`: `TELEGRAM_ADMIN_ID=...` (несколько id через запятую) и перезапустите сервер.

Если в терминале «Telegram недоступен» или «fetch failed», значит компьютер не может открыть api.telegram.org (часто его блокирует провайдер, хотя само приложение Telegram работает). Варианты: включить VPN в режиме «на весь компьютер» (TUN), или указать в `.env` HTTP-прокси VPN-клиента: `TELEGRAM_PROXY=http://127.0.0.1:10809` (порт смотрите в настройках клиента: v2rayN, Hiddify, Clash и т. п.), или запустить приложение на зарубежном VPS. Проверка: откройте в браузере https://api.telegram.org, должна открыться страница Telegram.

Команды бота для администратора: `/stats` за сегодня, `/yesterday` за вчера. Остальным бот отвечает только на `/id`. Отправить отчёт вручную можно во вкладке «Источники». Отчёт уходит один раз в день: если сервер был выключен в 20:00, отчёт придёт сразу после запуска в тот же день. Сервер должен работать постоянно, иначе отправка не произойдёт.

## ИИ (Claude API)

Ключ `ANTHROPIC_API_KEY` в `.env`. Модель по умолчанию `claude-opus-5-5`, меняется в `ANTHROPIC_MODEL` (например `claude-sonnet-5-5` дешевле). Ответ ИИ проверяется по схеме (`sentiment`, `topic`, `urgency`, `draft_reply`), при ошибке повтор с экспоненциальной задержкой; отзыв остаётся в статусе «Новый», пока не обработается.

## Чего пока нет (из ТЗ)

Вход по логину и ролям, модерация черновиков в Telegram-боте (кнопки «Одобрить/Изменить/Перегенерировать»), резервное копирование БД.
